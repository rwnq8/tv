# TV

A TV-style channel player at https://rwnq8.github.io/tv/ . Static site on GitHub Pages; `catalog.json` is rebuilt every 4 hours by `.github/workflows/catalog.yml` from YouTube RSS, Internet Archive, Vimeo, PeerTube and Dailymotion. Keys: up/down channel, 1-8 direct, G guide, L like, F fullscreen, right arrow next. Likes and history stay in the browser.
